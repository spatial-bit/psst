# Security

## Supported versions

Psst has not released a supported version yet.

## Version-one trust boundary

Psst version one assumes that every process able to reach the relay is trusted. Do not expose it to the internet, hostile LANs, public Wi-Fi, or untrusted tenants.

Resume tokens provide continuity and accidental collision prevention. They are not a defense against a malicious participant already present on the network.

## Reporting a vulnerability

Until a private reporting channel is configured, do not publish exploit details in a public issue. Contact the repository owner through their GitHub profile and request a private reporting path.
