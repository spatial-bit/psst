# Contributing

Psst is pre-release. Begin with the PRD and current roadmap before proposing code.

Every change must:

- map to a requirement or an explicitly reviewed requirements revision;
- preserve the architectural boundaries in `AGENTS.md`;
- include tests appropriate to its risk;
- pass formatting, linting, and the workspace test suite;
- avoid committing secrets, local databases, build outputs, or machine-specific state.

Use focused commits and draft pull requests. Risk-bearing changes require review by someone other than the implementer.
